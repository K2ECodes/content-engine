# Tool audit

## What it's for
Pay for fewer tools that know your work.

## Before you start
Ask for anything missing: a list of the tools you pay for and what you use each for.

## Steps
1. For each tool, write what it knows about your business: files, SOPs, examples, history.
2. Mark the overlap between tools.
3. Recommend keep, cut or replace, with 1 reason each.

## Rules
- Don't recommend a new tool unless asked.
- Mark guesses about pricing as guesses.

## Done looks like
A 1-page table with a keep or cut for every tool.
