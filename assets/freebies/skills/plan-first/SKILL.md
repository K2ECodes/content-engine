# Plan first

## What it's for
See what it will do before it does it.

## Before you start
Ask for anything missing: the task and the tools or accounts it can use.

## Steps
1. Write the plan: numbered steps, what each touches, and what can't be undone.
2. Wait for yes, edit or no.
3. Then do exactly the approved steps and report back.

## Rules
- Never start acting before the yes.
- If the plan has to change mid-way, stop and ask again.

## Done looks like
A plan the user approves in 1 read, then a done report.
