# Skill test

## What it's for
Find out where a skill gets it wrong before a customer does.

## Before you start
Ask for anything missing: the skill, and 3 past cases with what you actually did.

## Steps
1. Run the skill on each case.
2. Compare each result with what the user actually did.
3. List every difference that matters.
4. Suggest 1 line to add to the skill for each mistake.

## Rules
- Don't change the skill yourself. Suggest, the user decides.
- Test anything that sends or pays with drafts only.

## Done looks like
A short table: case, what it did, what you did, the fix.
