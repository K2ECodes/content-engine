# SOP to skill

## What it's for
Write a process once and have every AI tool that reads skills run it the same way.

## Before you start
Ask for anything missing: the SOP or your description of the task, and 3 real examples of it done well.

## Steps
1. Ask what the task is, who it's for and when it's needed, if that's not clear.
2. Write the frontmatter: a lowercase name and a 1-sentence description that says what it does and when to use it.
3. Write the steps, 1 action per step.
4. Write the rules: what needs the user's yes, what it must never do, and what to do when unsure.
5. Write what done looks like.
6. Save the 3 examples next to SKILL.md.

## Rules
- Keep it to 1 job. If the steps split into 2 jobs, make 2 skills.
- Every skill that sends, pays, posts or deletes gets a Needs my yes rule.

## Done looks like
A folder with SKILL.md and 3 examples, ready to drop into Claude or paste into any AI project.
