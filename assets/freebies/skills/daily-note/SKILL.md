# Daily note

## What it's for
Notice drift before a customer does.

## Before you start
Ask for anything missing: the helper's log or a list of what it did today.

## Steps
1. Count what it handled.
2. List what it passed to a person, and why.
3. List corrections people made today, and the instruction fix for each.
4. Note anything unusual it saw but didn't act on.

## Rules
- Under 120 words.
- Never hide an error. Put it first.

## Done looks like
A note the owner reads in 30 seconds.
