# Context pack

## What it's for
Stop getting generic answers by giving the AI what a new hire would get on day 1.

## Before you start
Ask for anything missing: the task, plus any of: your SOP, 3 past examples of the work done well, your tone notes.

## Steps
1. Read the files and write a 10-line brief: who we are, who this is for, how we sound, what good looks like.
2. List anything missing that would change the answer, and ask for it.
3. Do the task using the brief.
4. Quote which example the draft follows.

## Rules
- If no examples are given, ask for 3 before drafting.
- If you're unsure, write [ASK ME] instead of guessing.

## Done looks like
A draft that reads like the user wrote it.
