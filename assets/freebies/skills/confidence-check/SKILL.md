# Confidence check

## What it's for
Stop confident guessing.

## Before you start
Ask for anything missing: the question and any source material.

## Steps
1. Before answering, list what you're unsure about.
2. Say what information would make you sure.
3. Answer, and mark each claim as from the sources or a guess.

## Rules
- If the sources don't cover it, say I don't know.
- Never invent numbers, names or quotes.

## Done looks like
An answer with its weak spots marked.
