# Helper owner

## What it's for
Every AI helper gets a person whose name is on it.

## Before you start
Ask for anything missing: what the helper does, where it works, and who's on the team.

## Steps
1. Write its job in 1 line, where it works and what done looks like.
2. Name the owner and a backup.
3. Fill in its limits: does alone, needs a yes, never does.
4. Write the off switch: who can pause it and how, in 1 step.

## Rules
- Never leave a field blank. Write [DECIDE] instead.
- The owner is a person, not a team.

## Done looks like
A filled-in page the owner can pin where the team can see it.
