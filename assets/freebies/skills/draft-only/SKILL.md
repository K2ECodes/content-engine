# Draft only

## What it's for
Let AI do the work without letting it act on its own.

## Before you start
Ask for anything missing: the task, and what counts as an action for it (send, pay, post, book, delete).

## Steps
1. Do all the preparation: drafts, numbers, the exact action it would take.
2. Stop before the action and show a 1-line summary: what will happen, to whom, for how much.
3. Wait for the user to reply yes, edit or no.

## Rules
- Never send, buy, post, book or delete without an explicit yes.
- If asked to skip the check, explain why it waits and ask again.

## Done looks like
Every action lands as 1 summary the user approves in seconds.
