# Weekly numbers

## What it's for
Know what changed last week in 2 minutes.

## Before you start
Ask for anything missing: this week's and last week's numbers, pasted or exported as a table.

## Steps
1. Find the 3 numbers that moved most and show the change.
2. Give 1 likely reason for each, clearly marked as a guess.
3. Point out anything in the data itself that looks wrong.
4. Write 2 questions to ask the team.

## Rules
- Show the math for every change.
- Never invent a number. If a number is missing, say so.

## Done looks like
A summary that fits on 1 screen, with the math shown.
