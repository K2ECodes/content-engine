SOP to Skill Sheet
01

The template

The basics

A skill is a folder named after the job, with this file inside, called SKILL.md. Add your 3 examples to the same folder.

The 2 lines that matter most

The name and the description at the top. The AI reads the description to decide when to use the skill, so say what it does and when.

No skills support?

Paste the same text into a project's instructions in any AI chat tool. It still works.

You approve

Anything it sends, buys, posts or deletes. Write that down in Rules, every time.

SKILL.mdFill in the brackets
--- name: [job-name-in-lowercase] description: [What it does, in 1 sentence. Use when [the moment someone needs it].] --- # [Job name] ## What it's for [1 line: the outcome, and who it's for.] ## Before you start [What you need: the files, notes or numbers it should ask for if missing.] ## Steps 1. [1 action per step, plain words] 2. [...] 3. [...] ## Rules - Needs my yes before: [sending, paying, posting, deleting] - Never: [promise a date, price or refund] - If unsure: write [ASK ME], don't guess ## Done looks like [How you'd know it's right at a glance.] ## Examples See the 3 examples in this folder.
02

Writing tips that save a rewrite

A

Start from what you did

Talk through the task out loud while you do it. Turn the transcript into steps.

B

1 job per skill

If the steps split into 2 jobs, make 2 skills. Short skills fail less.

C

Examples beat adjectives

"Friendly but brief" means nothing. 3 real emails you sent mean everything.

D

Fix the skill, not the output

When it gets something wrong, add 1 line to the skill so it can't happen again.

03

A worked example

The SOP it came from

The weekly client update email. Same shape every Friday, about 30 minutes to write by hand.

Its 3 examples

The 3 best updates sent last month, pasted in as files, names removed.

Time now

About 5 minutes: paste in the week's notes, read the draft, fix 1 or 2 lines, send.

You approve

Every email before it goes. It drafts, it never sends.

SKILL.mdweekly-client-update
--- name: weekly-client-update description: Drafts the Friday update email to a client from my notes. Use when I paste a week's notes and say "client update". --- # Weekly client update ## What it's for A short Friday email so the client knows where things stand without a call. ## Before you start Ask for: client name, this week's notes, next week's plan. If any is missing, ask. ## Steps 1. List what got done, as 3 to 5 bullets 2. Flag anything late, with the new date 3. Say what happens next week 4. End with 1 question that needs their input ## Rules - Needs my yes before: sending anything - Never: promise a date not in my notes - If unsure: write [ASK ME] ## Done looks like Under 150 words. Readable on a phone. ## Examples See the 3 examples in this folder.

Test it on last week before you trust it

  • Run it on last week's notes and put its draft next to the email you actually sent.
  • Every difference that matters becomes 1 new line in the skill.
  • Run it again. When 2 drafts in a row need no real fixes, it's ready for this week.
